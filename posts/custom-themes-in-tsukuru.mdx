Theme customization is one of the most requested features for Tsukuru. In this draft, we are exploring how it will work.

## What to Expect

The upcoming theme system will allow you to:

- Change primary and accent colors
- Switch between light and dark mode
- Choose from a set of built-in fonts
- Customize the layout width and spacing

## How It Will Work

Themes will be defined in a simple configuration file. Here is a preview of what it might look like:

```json
{
  "theme": {
    "mode": "dark",
    "primaryColor": "#6366f1",
    "font": "inter",
    "layout": "wide"
  }
}
```

## Status

This feature is still in development and not yet available. Stay tuned for updates in future releases.
