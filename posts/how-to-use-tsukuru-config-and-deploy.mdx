Tsukuru makes it easy to set up a modern static blog in minutes...

```
image: string (required)
title: string (required)
description: string (required)
date: string (required)
author: string/array<string> (optional)
tags: array<string> (optional)
category: string (optional, default will be set paperwrite)
canonical: string (optional)
slug: string (optional, default will be set filename)
codelink: string (optional, if not added, no shortlinks will be generated.)
draft: boolean (optional, by default will be set false)
```
