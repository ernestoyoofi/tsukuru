This post demonstrates every custom MDX component available in Tsukuru. Copy the code blocks to use them in your own posts.

## Callout

<Callout type="info" title="Heads up">
This is an info callout. Use it for tips and neutral notes.
</Callout>

```mdx
<Callout type="info" title="Heads up">
This is an info callout. Use it for tips and neutral notes.
</Callout>
```

Available `type` values: `info`, `success`, `warning`, `danger`.

<Callout type="success" title="It works">
Your setup is complete and everything is running.
</Callout>

<Callout type="warning" title="Be careful">
This action cannot be undone once confirmed.
</Callout>

<Callout type="danger" title="Do not do this">
Never commit your secret keys to a public repository.
</Callout>

## Badge

New posts can be marked with a <Badge>default</Badge> badge, or highlight
something as <Badge variant="info">info</Badge>, <Badge variant="success">done</Badge>,
<Badge variant="warning">beta</Badge>, or <Badge variant="danger">breaking</Badge>.

```mdx
<Badge>default</Badge>
<Badge variant="info">info</Badge>
<Badge variant="success">done</Badge>
<Badge variant="warning">beta</Badge>
<Badge variant="danger">breaking</Badge>
```

## Accordions

<Accordions>
  <Accordion title="Do I need a database?">
    No. Tsukuru reads `.mdx` files from the `posts/` folder, so there is
    nothing to host besides static files.
  </Accordion>
  <Accordion title="Where do images go?" open={true}>
    Put post images under `public/image/` and reference them from frontmatter.
  </Accordion>
</Accordions>

```mdx
<Accordions>
  <Accordion title="Do I need a database?">
    No. Tsukuru reads `.mdx` files from the `posts/` folder.
  </Accordion>
  <Accordion title="Where do images go?" open={true}>
    Put post images under `public/image/`.
  </Accordion>
</Accordions>
```
